# 💬 Let's Chat Web App V5

> **Status:** Archived / Legacy Project  
> *This repository serves as a historical record of my early real-time web communication and messaging application experiments.*

---

## 📌 Overview
This repository contains the fifth iteration of a real-time web-based chat application. The project explores multi-user chat rooms, live message synchronization, user authentication flows, and dynamic client-side DOM rendering.

## 🛠️ Tech Stack
* **HTML5:** Structural layout for login screens, chat lobbies, and message dashboards.
* **CSS3:** Responsive styling, chat bubble design, and UI themes.
* **JavaScript:** Core application logic, event listeners, and dynamic DOM manipulation.
* **Firebase (Realtime Database / Authentication):** Cloud backend for instant message synchronization and user session management.
